Lets try SVG based animation:
The goal is to generate 20 frames for the animation, note that at this point the frames do not have to be production quality so as the animation.
We start with an emojis then:
1. Write a short text that describe each of the 20 frames.
2. Given the SVG of the emoji, we generate 20 SVGs, one for each description.

Tasks:
1. Write a tool that given an emoji generates a JSON array with 20 descriptions for the frames of the animation (use GPT 5.6 luna).
2. Given the emoji, SVG, metadata, and the JSON array of the descriptions, write a tool that generates 20 SVG files, one for each frame of the animation, based on the descriptions provided (use Sonnet 5.5 or Opus 5.5).
