Color Experiment:
    1. 
    Create a tool tools/data/extract-colors.ts
    when running bun extract-colors data/data.jsonl > data/colors.jsonl
    The tool extract all records with the color field and write them to data/colors.jsonl

    2. 
    update the train script
    When running `train --color-exp` it will:
    1. create a fresh encoder
    2. only load the data from data/colors.jsonl
    3. Train the Encoder + GAN model 
    4. save the models to `exp/enc.pt` and `exp/gan.pt`
