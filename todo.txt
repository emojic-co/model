Model architecture update.

We update the emoji prediction model.
This new architecture was already implemented once and we reimplement it again.

In the new architecture we have:

fuzzy search:
    tokenize the query
    for each of the keywords (from ii.json) calculate the max IoU with the query tokens
    output a dense vector of size len(keywords) with the max IoU for each keyword

A single shared emoji embedding component `EmojiEmbedding`:
    Just a table of size len(emoji_vocab) x EMOJI_EMBED_SIZE, where each row is the embedding of an emoji.

An `EmojiHead`:
    that projects the `TextEncoder` output to the emoji embedding space.

An `SearchHead` that projects:
    the fuzzy search output to the emoji embedding space.

A `Fusion` head:
    Maps the output of the `TextEncoder` to a number `a` in [0..1]
    Then outputs 
    `a * emoji_head_output + (1-a) * search_head_output`

The final ranked list is obtained by the matrix multiplication of the `EmojiEmbedding` table with the `Fusion` output.
