upsample emojis <list> - upsample exactly the emojis in the list (space ot comma separated)

upsample groups - upsample under-covered emoji groups (see details below)

all commands support the flags:
--per (samples per target, default 50)
--dry (don't run just tell)
--help

When upsampling groups the tool reads data/data.jsonl to count the frequency of each emoji in the data.jsonl file.
Then it reads the goals.yml, data/group.json, data/labels.json files and:
Find groups that are under-covered (i.e. below the stated goal) for each such group it will sample the missing number of emojis to reach the goal.
The emojis to sample are selected greedily by frequency in data/data.jsonl (i.e. for each group upsample emojis that are not in labels.json but have the highest frequency in data.jsonl break tie randomly) note that missing emojis that are also not in data.jsonl have freq=0 and are upsampled as a last resort.
