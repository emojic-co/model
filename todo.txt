Lets make each train -> report -> analysis -> updates loop concrete.
After each loop iteration we should write a new file:
goal/<data>-<git sha>.yml
that looks something like this:

goals:
    keyword:
        exact:
            acc@1: 0.9
        fuzzy:
            acc@1: 0.8
            acc@5: 0.9

    text: 
        acc@1: 0.8
        acc@5: 0.85
        acc@10: 0.9

    colors:
        energy: 0.03
        red: 0.2
        green: 0.1
        blue: 0.1
        dark: 0.1
        bright: 0.1

    coverage:
        vocab: 700
        diversity: 0.6



The file lists all the goals we want to achieve for the next iteration, and it will be used to derived our next steps:
    data: 
        upsampling
        quality
        slicing
    
    model/training:
        configuration
        architecture
        loss function
    
    analysis:
        new analysis tools


So the loop should look like this:
    1. train 
    2. report 
    3. analysis
    4. writing new goals file
    5. derived a concrete plan
    6. implement
    7. start over
